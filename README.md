## Interopérabilité - Projet circulations

### Auteurs

- Nicka Ratovobodo
- Nino Arcelin

### Description

Ce projet consite en une page asynchrone en JS qui criose les données de plusieurs API afin de faciliter la prise de décision pour les déplacements en vélo collectif.

### Fonctionnalités

- Affichage de la météo du jour
- Affichage de la carte de la ville avec les stations de vélos collectifs et leur adresse
- Affichage des stations de vélos avec leur disponibilité
- Données liées à la qualité de l'air
- Données liées au Covid

### Technologies utilisées

- HTML/CSS
- JavaScript
